# Minimalist Portfolio - Asif Al Faisal

This is a minimalist, two-tone portfolio website generated from `cv.tex`.

## Files
- `index.html`: Main content file.
- `style.css`: Styling (Dark Slate & Off-White).
- `script.js`: Smooth scrolling and animations.

## How to Deploy to GitHub Pages

1.  **Create a New Repository** on GitHub (e.g., `my-portfolio`).
2.  **Push the Files**:
    ```bash
    git init
    git add .
    git commit -m "Initial commit"
    git branch -M main
    git remote add origin https://github.com/YOUR_USERNAME/my-portfolio.git
    git push -u origin main
    ```
3.  **Enable GitHub Pages**:
    - Go to Repository **Settings**.
    - Scroll down to **Pages**.
    - Select `main` branch as the source.
    - Click **Save**.

Your site will be live at `https://YOUR_USERNAME.github.io/my-portfolio/`.
